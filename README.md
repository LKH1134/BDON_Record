# BDON Record

[**Workers 운영 페이지 바로가기 →**](https://bdon-record.kh12.workers.dev)

뱅드림! 아워 노트의 악곡별 플레이 기록을 저장하고 레이팅을 확인하는 웹사이트입니다. Cloudflare Workers에서 화면과 API를 제공하고, 계정과 기록은 Cloudflare D1에 저장합니다. 현재 91곡과 Expert / Hard / Normal / Easy 난이도를 지원합니다.

## 주요 기능

- 계정 만들기·로그인·로그아웃과 계정별 플레이 기록 저장
- 곡·난이도별 클리어 / 풀콤보 / 올퍼펙트 기록
- 편집 모드에서 여러 기록을 변경한 뒤 한 번에 저장
- 원문·번역명·밴드 검색, 밴드·기록 필터, 레벨 오름차순·내림차순 정렬
- 난이도별 기록 집계, 곡별 획득 레이팅과 계정 전체 레이팅 표시
- 레이팅 옆 **상세 보기**로 실제 반영된 상위 50곡과 난이도·기록·획득 레이팅 확인
- 네이비·블루 테마와 모바일 화면 지원

## 사용 방법

1. [운영 페이지](https://bdon-record.kh12.workers.dev)에 접속해 오른쪽 위 **로그인 → 계정 만들기**에서 계정을 만듭니다. 기존 계정이 있다면 로그인합니다.
2. **기록 편집**을 누르고 난이도를 선택합니다.
3. 곡 우측의 **클리어 / 풀콤보 / 올퍼펙트** 중 하나를 체크합니다. 다른 상태를 고르면 교체되고, 선택한 상태를 다시 누르면 기록이 해제됩니다.
4. 원하는 만큼 수정한 뒤 **저장**을 누릅니다. 변경분을 한 번에 전송하고, 저장에 성공하면 편집 모드가 종료됩니다. 난이도·검색·필터를 바꿔가며 편집한 기록도 함께 저장됩니다.
5. 변경을 버리려면 **취소**를 누릅니다. 편집 전 기록으로 돌아갑니다.

체크를 바꿀 때마다 저장 요청을 보내지 않습니다. 취소하거나 변경 없이 편집을 종료할 때도 저장 요청이 발생하지 않습니다. 저장에 실패하면 임시 변경 내용을 유지해 다시 저장할 수 있습니다.

저장 전 레이팅과 집계는 임시 기록을 기준으로 갱신됩니다. 미저장 변경은 브라우저 메모리에만 있으므로 새로고침하거나 페이지를 닫으면 사라집니다.

## 레이팅과 집계

현재 운영 페이지의 차트별 레이팅은 **곡 레벨 × 기록 계수**로 계산합니다. 계산값 2배 변경은 아래 다음 작업 메모에 기록된 미적용 항목입니다.

| 기록 | 계수 |
| --- | --- |
| 클리어 | 1.00 |
| 풀콤보 | 1.05 |
| 올퍼펙트 | 1.10 |

같은 곡의 여러 난이도 중 가장 높은 레이팅 하나를 선택하고, 그중 **상위 50곡을 합산**합니다. 기록한 곡이 50곡 미만이면 기록이 있는 곡만 합산합니다. 검색·필터·난이도 탭을 바꿔도 계정 전체 레이팅의 계산 범위는 바뀌지 않습니다.

- 전체 레이팅은 요약 영역의 가장 오른쪽에 표시합니다.
- 곡별 레이팅은 선택한 난이도를 기준으로 레벨 왼쪽에 표시합니다.
- 클리어 집계에는 풀콤보·올퍼펙트가, 풀콤보 집계에는 올퍼펙트가 포함됩니다.
- 기록 필터는 선택한 상태와 정확히 일치하는 곡을 표시합니다.

레이팅 옆 **상세 보기**를 누르면 합계에 반영된 최대 50곡만 획득 레이팅 내림차순으로 확인할 수 있습니다. 곡마다 반영된 난이도·레벨·기록과 레이팅을 표시하며, 상세 합계는 메인 레이팅과 같습니다. 기록이 50곡 미만이면 기록한 곡만 표시하고, 목록의 검색·필터·난이도 탭에는 영향을 받지 않습니다. 추가 서버 요청 없이 열리며 편집 중에는 임시 기록 기준임을 안내합니다.

상세 보기 하단에는 다음 설명을 표시합니다.

> 해당 레이팅은 공식적인 자료가 아니며, 실력의 척도를 예상하기 위한 가상 지표입니다.

## 계정과 기록

저장한 기록은 D1에 보관되며, 다른 기기에서도 같은 계정으로 로그인하면 이어서 사용할 수 있습니다. 게임 계정과는 별도의 사이트 계정이며, 게임 UID로 클리어 현황을 자동으로 불러오는 기능은 아직 구현하지 않았습니다.

로그인 없이도 악곡 검색·난이도 확인·정렬을 사용할 수 있습니다. 기록 편집과 계정별 레이팅 확인에는 로그인이 필요합니다.

## Workers 개발과 배포

Node.js 24.15 이상을 준비하고 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run db:local
npm run dev:worker
```

Wrangler가 출력하는 로컬 주소에 접속합니다. 기본 주소는 `http://127.0.0.1:8787`입니다. 로컬 개발은 `.wrangler/`의 별도 D1을 사용하며 운영 계정·기록과 분리됩니다.

```sh
# 테스트 및 배포 번들 검증
npm test
npm run check:worker

# Cloudflare 인증 후 운영 화면과 API 배포
npm run deploy:worker
```

Cloudflare 인증·D1 연결·새 환경의 migration 설정은 [Workers·D1 안내](docs/CLOUDFLARE.md)를 참고합니다. 저장소의 GitHub Actions는 Pages 미리보기용이므로, GitHub 푸시만으로 Workers 배포가 완료됐다고 가정하지 않습니다.

악곡 데이터의 원본은 `Data.xlsx`입니다. 데이터를 수정했다면 Python 3으로 `npm run sync-data`를 실행해 `data/catalog.json`도 갱신합니다. 기존 곡·문자열 ID는 저장 기록과 연결되므로 유지합니다.
